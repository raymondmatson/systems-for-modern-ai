# Torus topology

## Overview

A torus is a regular multidimensional network topology in which each node connects to nearby neighbors and the edges of each dimension wrap around. This creates multiple routes through a repeating physical pattern and avoids the edge nodes found in a simple mesh.

## Why It Matters

Accelerator pods can use torus-style connectivity to provide scalable local communication with predictable neighbor relationships. The topology influences routing, bisection behavior, failure handling, and how distributed workloads should be placed on the physical system.
